# Data

Place the dataset here as `heart.csv`.

Required columns: `age, sex, cp, trestbps, chol, fbs, restecg, thalach, exang, oldpeak, slope, ca, thal, target`

Sources (pick one with these standard columns):
- UCI Heart Disease (Cleveland): https://archive.ics.uci.edu/dataset/45/heart+disease
- Kaggle "Heart Disease Dataset" (`heart.csv`, same 13 features + `target`)

If your file names the label differently (e.g. `num`), rename it to `target` and make it binary (0 = no disease, 1 = disease).

The CSV itself is git-ignored. Link to the source in your README instead of committing the data.
